# Multiple Accounts with Mutt

> "All mail clients suck. This one just sucks less."
> &mdashMichael R. Elkins in 1995

Since mutt only reads your config once at the start-up, you can write a small executable to quickly replace your ~/.muttrc file with a given profile.

For example, on my system, I type this to open my work email:

```sh
email work
```

Simply create a file for each profile you want:

```sh
~/.mutt/muttrc.work
~/.mutt/muttrc.home
~/.mutt/muttrc.org
```

Then add this to your `PATH`,  e.g. `/usr/local/bin/email`:

```
#!/bin/bash

profile=${1:-"$(whoami)"}
shift

MUTT_PATH="$HOME/.mutt"
MUTTRC="$MUTT_PATH/muttrc"
if [ ! -f "$MUTTRC.$profile" ]; then
  echo "Unable to find $MUTTRC.$profile" >&2
  exit 1
fi

echo "#
# DO NOT EDIT THIS FILE
# GENERATED AUTOMATICALLY by $0
#
" >"$MUTTRC"

cat "$MUTTRC.$profile" >> "$MUTTRC"
mutt "$@"
```
