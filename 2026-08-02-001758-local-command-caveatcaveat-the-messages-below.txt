the circles, like they're related to lenses. Then a rounded sci-fi font         
PARASPACE, you know the A that feels like a wide arch and the P matches it --   
like Supernova font. Any questions? We can start with the hero then fix the     
feature cards to match it.

⏺ Design locked. Building it:

  - Signature — the Venn is the product: two lenses overlap, and the overlap is
  what's shared (host, kernel, auth) while the crescents are what's isolated.
  The page's only light source is that intersection.
  - One primitive — the arch radius that draws the wordmark's P and A is the
  same circle the lenses are. P is the arch closed at the bar; A is the same
  arch with both legs run to the baseline.
  - Two physics — dark mode is a CRT: lenses screen-blend additively, wordmark
  carries RGB fringing. Light mode is a faded print: the same plates multiply
  like ink, and the fringe becomes CMYK misregistration.

⏺ Built on branch poster-lander (uncommitted — git checkout main shows the old
  lander). Dev server: npm run site.

  The wordmark is drawn, not typeset. One arch of radius 30.5 on a 78×100 body,
  stroked at 17, builds every glyph — P is that arch closed at the bar, A is the
  same arch with both legs run to the baseline, R is P with a leg. S and C are
  arcs of the same family, so every curve on the page, including the two lenses,
  comes off one circle. No display font ships at all now.

  The Venn is the product, not decoration. Two workspaces on one machine share
  the host, the kernel and the project's credentials — that's the overlap — and
  share nothing else, which is the two crescents. The lenses separate out of a
  single circle over 1.5s on load, then drift on coprime periods. The page's
  only light source is the intersection, with the amber bed under it.

  Two physics rather than one palette recolored. Dark is a CRT: lenses
  screen-blend additively, video-black lifts to #14151a, the wordmark carries
  RGB fringing. Light is a faded print: the same two plates multiply like ink on
  aged stock, and the fringe becomes CMYK misregistration. One knob, --pv-d,
  accounts for ink needing to be laid down harder than light.

  Changes: Poster.vue and Wordmark.vue are new; the poster mounts in
  home-hero-before (no hero: frontmatter, so VitePress's default hero doesn't
  render) and the terminal moves to home-hero-after, its orbit dressing removed
  since the poster owns the space motif now. Feature cards are re-lit off the
  lens tint with circular icon apertures. Sky.vue and Anton SC are deleted — the
  sky is replaced and nothing rendered the font, which the repo's own "no font
  nobody renders" rule settles.

  Checked at 1440 and 390 wide, both themes, and with reduced motion forced
  (lands on the final state, no animation).

  One thing I could not verify: bin/lint did not complete. shellcheck isn't
